Acerca de EduAssist

📚 ¿Qué es EduAssist?

EduAssist es una plataforma diseñada para facilitar el control y seguimiento de estudiantes dentro de una institución educativa. Permite registrar información académica y gestionar novedades como permisos, incapacidades y citas médicas de manera organizada y segura.

🎯 Objetivos

  • Administrar estudiantes.
  • Registrar novedades académicas.
  • Controlar permisos e incapacidades.
  • Generar estadísticas en tiempo real.
  • Facilitar el trabajo administrativo.

⚙ Tecnologías utilizadas

HTML5
CSS3
JavaScript
Supabase
SQL
